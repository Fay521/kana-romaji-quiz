## 介绍

一个很单纯的五十音测验的平台。有错题本,笔画等功能 可以让你更方便的学习五十音。

## 功能

- 假名的笔画显示动画
- 错题本,更方便你来复习易错字
- 答题的进度跟踪和错题显示
- 简洁好用的界面
- 开源网页，很多功能可以按照自己的想法自定义

## 快速开始

1. 克隆项目：
   ```bash
   git clone https://github.com/Fay521/kana-romaji-quiz.git
   cd kana-romaji-quiz
   ```

2. 双击使用浏览器打开 `index.html` 即可

## Overview

A web-based quiz for practicing Japanese Kana (Hiragana & Katakana) and Romaji. Perfect for Japanese learners who want to master the fundamental syllabary.

## Features

- Interactive Kana-Romaji conversion quiz
- Real-time feedback
- Score tracking
- Clean and simple interface
- Pure frontend application

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Fay521/kana-romaji-quiz.git
   cd kana-romaji-quiz
   ```

2. Open `index.html` in your browser
