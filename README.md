## 介绍

一个五十音（平假名和片假名）与罗马字测试的网页应用。帮助日语学习者快速掌握日文基础音节。

## 功能

- 五十音和罗马字互转测试
- 实时答题反馈
- 进度跟踪和成绩显示
- 简洁好用的界面
- 纯前端应用，无需后端

## 快速开始

1. 克隆项目：
   ```bash
   git clone https://github.com/Fay521/kana-romaji-quiz.git
   cd kana-romaji-quiz
   ```

2. 用浏览器打开 `index.html` 即可
