# Kana Romaji Quiz / 五十音测试

English | [中文](#中文说明)

## Overview

A web-based quiz application for testing and practicing Japanese Kana (平假名 & 片假名) and their Romaji (Latin alphabet) equivalents. This project helps learners of Japanese language master the fundamental syllabary system.

### Features

- 📝 Interactive quiz for Kana-Romaji conversion
- 🎯 Real-time feedback on answers
- 📊 Progress tracking and score calculation
- 🎨 Clean and user-friendly interface
- 🚀 Fast performance with pure HTML/CSS/JavaScript
- 💾 No backend required - runs entirely in the browser

### Technologies Used

- **HTML** (17.5%) - Page structure and layout
- **CSS** (28.6%) - Styling and responsive design
- **JavaScript** (53.9%) - Quiz logic and interactivity

### Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Fay521/kana-romaji-quiz.git
   cd kana-romaji-quiz
   ```

2. Open `index.html` in your web browser to start the quiz

### How to Use

1. Launch the application by opening the HTML file
2. Read the Kana character (or Romaji) displayed on the screen
3. Select or type the corresponding Romaji (or Kana)
4. Submit your answer and receive immediate feedback
5. Continue through all questions to complete the quiz
6. View your final score and review results

## 中文说明

## 概述

一个基于网页的五十音（平假名和片假名）及其罗马字（拉丁字母）测试应用。这个项目帮助日语学习者掌握日文基础音节系统。

### 功能特性

- 📝 五十音和罗马字互转的交互式测试
- 🎯 实时答题反馈
- 📊 进度跟踪和成绩计算
- 🎨 简洁易用的用户界面
- 🚀 高性能纯前端应用
- 💾 无需后端支持 - 完全在浏览器中运行

### 技术栈

- **HTML** (17.5%) - 页面结构和布局
- **CSS** (28.6%) - 样式和响应式设计
- **JavaScript** (53.9%) - 测试逻辑和交互功能

### 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/Fay521/kana-romaji-quiz.git
   cd kana-romaji-quiz
   ```

2. 在网络浏览器中打开 `index.html` 开始测试

### 使用方法

1. 打开HTML文件启动应用
2. 阅读屏幕上显示的五十音字符（或罗马字）
3. 选择或输入对应的罗马字（或五十音）
4. 提交答案并获得即时反馈
5. 继续完成所有题目
6. 查看最终成绩并复习结果
